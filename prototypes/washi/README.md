# 风格原型 05：和纸（Washi）

独立演示页，不参与 VitePress 构建。内容数据来自 `../_shared/data.js`。

## 打开方式

在仓库根目录运行：

```bash
npx http-server . -p 5199
```

然后访问 `http://localhost:5199/prototypes/washi/index.html`。

## 风格定位

- 视觉：留白禅意与和纸质感。极低对比纸本原色（`#F7F5F0` / `#141414`），淡淡植物纤维纹理，大面积呼吸留白。朱红印章（`#C8352B` 搭配朱砂印泥滤镜 `#seal-ink` 微渗墨边缘），竖排文字排版（`writing-mode: vertical-rl`）、数字直立（`text-combine-upright`）、枯山水同心涟漪、墨水晕染。字体采用和纸衬线体（Noto Serif SC / 思源宋体）搭配楷体笔触。
- 动效性格：如墨入水、随风缓行。起伏舒缓，不急促、不生硬，伴随呼吸节奏（600ms~1000ms），水墨自然晕开。
- 气质：静谧、内敛、空灵。

## 动效参数

| 变量         | 时长                         | 用途                   |
| ------------ | ---------------------------- | ---------------------- |
| `--breath-s` | 600ms                        | 短呼吸反馈、墨痕显隐   |
| `--breath`   | 800ms                        | 标准舒展、卡片展开     |
| `--breath-l` | 1000ms                       | 长呼吸叙事、页面沉降   |
| 水墨明暗切换 | 1600ms                       | 多中心墨晕径向渐变扩散 |
| `--ease`     | `cubic-bezier(.4, 0, .2, 1)` | 水流舒缓缓动           |

开启“减少动态效果”时，关闭墨晕动画与粒子循环，所有操作直接完成。
