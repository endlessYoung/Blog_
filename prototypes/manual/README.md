# 风格原型 01：工程手册（Manual）

独立演示页，不参与 VitePress 构建。

## 打开方式

在仓库根目录运行：

```bash
npx http-server . -p 5199
```

然后访问 `http://localhost:5199/prototypes/manual/index.html`。

## 风格定位

- 视觉：瑞士排版、12 栏网格、黑白灰加单一强调色（信号橙 `#FF4F00` / 克莱因蓝 `#2B3FFF`）、1px 细线分隔、等宽字体编号。
- 动效性格：精密仪器。快进快停，不弹跳；数字用里程表滚动；元素沿网格运动。
- 气质：硬朗、克制、理性。

## 包含的效果

| 位置     | 效果                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 首页刊头 | 网格线画出、字母错位归位、里程表数字（每会话一次，REPLAY 重播）                |
| 全局背景 | 光标附近网格线高亮                                                             |
| 目录     | 点线收紧、篇数滚动、章节依次滑入、翻牌预览、键盘导航                           |
| 图集     | 视口内运行的缩略交互图、拖动带惯性                                             |
| 转场     | View Transitions：编号与标题飞入文章页页眉，返回时反向飞回                     |
| 文章页   | 滚动叙事、CAS 调试器式交互图、代码与图双向高亮、页边刻度尺、链接预览、复制解码 |
| 全局     | Ctrl+K 索引台（FLIP 重排）、12 栏翻板明暗切换、强调色切换                      |

## 动效参数

| 变量             | 时长                          | 用途       |
| ---------------- | ----------------------------- | ---------- |
| `--motion-tick`  | 120ms                         | 微反馈     |
| `--motion-snap`  | 240ms                         | 展开、切换 |
| `--motion-glide` | 480ms                         | 页面转场   |
| 缓动             | `cubic-bezier(.16, 1, .3, 1)` | 进入       |
