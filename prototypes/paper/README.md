# 风格原型 02：纸本（Paper）

独立演示页，不参与 VitePress 构建。内容数据来自 `../_shared/data.js`。

## 打开方式

在仓库根目录运行：

```bash
npx http-server . -p 5199
```

然后访问 `http://localhost:5199/prototypes/paper/index.html`。

## 风格定位

- 视觉：温润书卷感。暖米色纸张底色（`#F4F0E8` / `#1F1B17`），细腻纸张噪点与纤维纹理（SVG 滤镜），左侧装订书脊压痕阴影，手绘墨迹抖动线（SVG 滤镜 `#pen`），书籍折角、丝带书签（随滚动拉伸刻度）。字体采用宋体 / 明朝体（Noto Serif SC / 思源宋体）搭配衬线英文字体 Georgia，注释与手写体采用楷体。
- 动效性格：翻书与墨迹。翻页时带 3D 透视书页翻折（`pageTurn` / `perspective(2600px)`），纸张明暗伴随翻折加深再回亮；墨迹书写与删除线划过（`ink-stroke`）；台灯聚光圈式明暗切换。
- 气质：沉静、典雅、人文书卷气。

## 包含的效果

| 位置     | 效果                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 首页刊头 | 书卷开卷，落款印章盖印，墨迹横线生长，章节卡片书架微动（每会话一次，REPLAY 重播）                      |
| 全局背景 | 纸张纤维噪点、左侧装订书脊立体阴影、双重纸纹质感叠加                                                   |
| 目录     | 书本目录排版、手绘点线连接、章节依次翻开滑入、书卡预览面板、键盘导航                                   |
| 图集     | 四幅手绘墨水插图（仅在视口内运行），水平滑动带惯性与边界阻尼，拖动后不误触打开                         |
| 日志     | 读书批注式更新日志，悬停显示墨水高亮与书签标记                                                         |
| 索引     | 按部首/拼音索引卡片，悬停预览条目卡片                                                                  |
| 转场     | View Transitions：3D 书页翻折进入文章页，编号与标题飞入页眉；返回时书页反向翻合                        |
| 文章页   | 单双栏书卷排版、滚动叙事、页边批注与浮出窥探（Peek）、代码与图双向高亮、丝带书签阅读刻度、底部页码书脚 |
| CAS 图   | 钢笔手绘交互图（SVG 墨水滤镜），读取时墨滴划线，写入成功时墨水浸润划除旧值，失败时红墨划叉震颤回退     |
| 全局     | Ctrl+K 索引卡片柜（FLIP 重排、卡片式预览）、台灯光圈扩散式明暗切换、代码复制反馈                       |

## 动效参数

| 变量            | 时长                           | 用途                   |
| --------------- | ------------------------------ | ---------------------- |
| `--motion-soft` | 400ms                          | 微反馈、卡片展开       |
| `--motion-page` | 600ms                          | 页面元素滑入、墨水生长 |
| `--motion-turn` | 760ms                          | 3D 翻书转场            |
| 明暗切换        | 780ms                          | 台灯光圈展开与收缩     |
| `--ease`        | `cubic-bezier(.65, 0, .35, 1)` | 平稳沉着翻页           |
| `--ease-out`    | `cubic-bezier(.33, 1, .68, 1)` | 手绘元素落位           |

开启“减少动态效果”时，所有动画与转场立即完成。
