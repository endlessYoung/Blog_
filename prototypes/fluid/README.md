# 风格原型 04：流体（Fluid）

独立演示页，不参与 VitePress 构建。内容数据来自 `../_shared/data.js`。

## 打开方式

在仓库根目录运行：

```bash
npx http-server . -p 5199
```

然后访问 `http://localhost:5199/prototypes/fluid/index.html`。

## 风格定位

- 视觉：全屏 WebGL 域扭曲噪声流体做底，深墨 `#0A0C10` 上流动熔岩珊瑚 `#FF5A36`、琥珀 `#FFB547`、深青 `#0E7C7B`、薄荷 `#CFF5E7`；亮色模式为暖白底配柔化后的同组色相。内容放在毛玻璃面板上，形状只用胶囊、圆和水滴，几乎没有直角与 1px 细线。
- 字体：标题用 Space Grotesk 可变字体（300–700），字重本身参与动效；中文用 Microsoft YaHei UI / PingFang SC / Noto Sans SC。
- 动效性格：流动。元素像液体一样连续变形、合并与分裂（SVG gooey 滤镜），缓动带轻微回弹。
- 气质：鲜活、沉浸、有生命感；进入文章页后背景安静下来，让位给阅读。

## 包含的效果

| 位置     | 效果                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 全局背景 | WebGL 流体随时间流动，跟随滚动偏移，指针附近的流场被轻轻吸引；文章页降为低对比、近乎静止的底色         |
| 首屏开场 | 流体从中心向外绽放，标题字重由细到粗生长并带液态位移，数据气泡弹出（每会话一次，REPLAY 重播）          |
| 首屏交互 | 指针靠近时标题字母变粗，数据气泡持续缓慢形变                                                           |
| 目录     | 悬停部分行时黏滞液块滑向该行并拉伸、融合；章节卡片依次浮出；预览面板以水滴扩散切换内容；键盘上下导航   |
| 图集     | 四张卡片各有一段液滴循环动画（仅在视口内运行），拖动带惯性，拖动后不会误触打开                         |
| 日志     | 悬停时液体从左向右注满整行                                                                             |
| 索引     | 按首字分组的胶囊词条，悬停预览对应文章                                                                 |
| 转场     | View Transitions：从点击点扩散的水滴形 clip-path 铺满进入文章，编号与标题飞入页眉；返回时收缩回原条目  |
| 文章页   | 滚动叙事、CAS 液滴交互图、代码与图双向高亮、左下角阅读液位（当前小节、剩余分钟、小节跳转）、链接预览   |
| CAS 图   | 内存是一团液体；读取时液滴从内存分离流向线程；写入成功时液滴融入内存并使其鼓起；失败时撞击、溅开、流回 |
| 全局     | Ctrl+K / `/` 搜索面板（从搜索按钮水滴展开、FLIP 重排、滑动高亮）、墨滴入水式明暗切换、复制按钮注满     |

## 动效参数

| 变量          | 时长 / 值                        | 用途                   |
| ------------- | -------------------------------- | ---------------------- |
| `--t-ripple`  | 180ms                            | 颜色、透明度等微反馈   |
| `--t-flow`    | 420ms                            | 黏滞液块滑动、字重变化 |
| `--t-pour`    | 760ms                            | 展开、注满、卡片浮出   |
| 页面转场      | 820ms（进入）/ 720ms（返回）     | 水滴扩散与收缩         |
| 明暗切换      | 1150ms                           | 墨滴边缘的扩散         |
| `--ease-goo`  | `cubic-bezier(.3, 1.35, .45, 1)` | 带轻微回弹的液体运动   |
| `--ease-flow` | `cubic-bezier(.65, 0, .35, 1)`   | 液滴在两点之间流动     |
| 流体渲染      | DPR 上限 1.5，内部分辨率 0.5 倍  | 标签页隐藏时暂停       |

开启“减少动态效果”或浏览器不支持 WebGL 时，背景退回为 CSS 渐变色块（减少动态效果时保持静止），转场和明暗切换直接完成。
