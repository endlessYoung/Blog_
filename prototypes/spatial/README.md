# 风格原型 03：空间（Spatial）

独立演示页，不参与 VitePress 构建。

## 打开方式

在仓库根目录运行：

```bash
npx http-server . -p 5199
```

然后访问 `http://localhost:5199/prototypes/spatial/index.html`。

## 风格定位

- 视觉：visionOS / macOS 式的层叠磨砂玻璃。低饱和渐变光斑缓慢漂移，面板有 20–28px 圆角、多层阴影、渐变高光描边，悬停时高光跟随指针。字体为 Space Grotesk 加系统中文字体。
- 动效性格：真实的阻尼弹簧。所有运动都由同一个弹簧求解器生成（WAAPI 关键帧和 CSS `linear()` 缓动），可以被打断，速度会延续；层次靠景深和模糊表达，而不是位移。
- 气质：轻盈、通透、安静的高级感。

## 包含的效果

| 位置     | 效果                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 首页     | 玻璃层从景深中浮起、字母依次落位、数字弹簧计数、三层卡片指针视差（每会话一次，REPLAY 重播）        |
| 全局背景 | 纯 CSS 漂移光斑与细噪点，明暗两套色板                                                              |
| 目录     | 卡片倾斜抬升与镜面高光、部分弹簧展开、章节依次浮现、预览面板弹簧换卡、键盘导航                     |
| 图集     | 视口内才运行的缩略动画、拖动带惯性并以弹簧吸附、拖动后不误触点击                                   |
| 日志     | 悬停胶囊在条目间弹簧跟随                                                                           |
| 转场     | View Transitions：卡片、标题、编号飞入文章页，其余页面后退并模糊；返回时反向飞回原位               |
| 文章页   | 滚动叙事、CAS 玻璃胶囊交互图（值球沿弧线飞行，成功脉冲、失败回弹）、代码与图双向高亮、阅读进度胶囊 |
| 全局     | Ctrl+K / `/` 命令面板（弹簧 FLIP、背景后退模糊）、日落 / 日出式明暗切换、链接预览、复制反馈        |

## 动效参数

弹簧均为质量 1，由求解器实时计算，结果写入 `--spring-*` 与 `--spring-*-dur` 两组 CSS 变量。

| 预设     | 刚度 k | 阻尼 c | 实测时长 | 用途                             |
| -------- | ------ | ------ | -------- | -------------------------------- |
| `snappy` | 420    | 32     | ≈ 470ms  | 微反馈、收起、胶囊跟随、失败撞击 |
| `gentle` | 150    | 21     | ≈ 740ms  | 展开、页面转场、明暗切换         |
| `bouncy` | 300    | 15     | ≈ 930ms  | 浮起入场、预览弹出、失败回弹     |

不支持 `linear()` 的浏览器回退为 `cubic-bezier`；开启“减少动态效果”时，所有运动改为直接切换。
