# 站点更新日志与演进记录

记录技术博客的架构迭代、主题系统开发及重大内容演化。

## [v2.0.0] - 2026-10-06 (feat/themes)

### 新增与重构

- **三主题外观系统上线**：
  - **工程手册 (Engineering)**：基于 12 栏精密网格与无特效稳定基线的默认主题；
  - **空间透镜 (Spatial)**：毛玻璃与物理弹簧动画主题；
  - **流体着色器 (Fluid)**：原生 WebGL 流光极光深色主题。
- **架构升级**：
  - CSS 变量 Tokens 架构重构，解耦样式变量与骨架布局；
  - 首屏注入 Anti-FOUC 内联脚本，彻底消除主题切换闪烁；
  - 核心交互图表状态机组件化（CAS 原语动态可视化）；
  - 全站 300+ 篇技术笔记统一链接结构与 SSR 静态输出。
- **功能页补全**：新增 `/catalog/` 目录索引、`/figures/` 交互图集、`/changelog/` 更新日志与 `/archive/` 全站索引。
