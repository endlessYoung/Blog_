## 2. 相同与高度接近的部分总结 (可 100% 共享变量)

1. **中文正文字体栈与字号阶梯**：
   - 三者统一使用操作系统本地中文字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif`；
   - 正文基准字号一律 `16px`，行高 `1.7`，段间距 `1.2em`，正文阅读区最大宽度锁定为 `740px`（约 38~42 字符宽）。
2. **展示标题字体**：
   - 均采用自托管、子集化的 `Space Grotesk`，字重 `300~700`，字距 `--letter-spacing: -0.02em`。
3. **主强调色在工程与流体中的互通性**：
   - 工程主题 `--accent: #ff4f00` 与流体主题 `--accent: #ff5a36` 视觉色调极其接近（均为极具穿透力的高饱和工程橙/珊瑚橙）；空间主题采用科技波蓝 `--accent: #6e9bff`。三者均通过单一变量 `--accent` 承接。
4. **文章骨架与布局基准**：
   - 栅格列宽、断点系统（`480px / 768px / 1024px / 1280px`）、代码块基础结构、正文目录结构、行内链接样式完全一致。

## 3. 必须换专属组件（无法只换变量）的部分

根据需求 §3.3 原则，只有以下 3 个关键专属插槽允许且必须挂载专属组件，其余一律共用骨架：

| 专属插槽区域                           | 工程主题组件 (`themes/engineering/`)                                                               | 空间主题组件 (`themes/spatial/`)                                                                  | 流体主题组件 (`themes/fluid/`)                                                                       | 专属组件技术差异                                  |
| :------------------------------------- | :------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------- | :------------------------------------------------ |
| **1. 首页 Hero (`Hero.vue`)**          | **工程仪表大字标**：<br>`ENDLESSYOUNG` 精密工牌、Odometer 翻牌数字仪表、四象限参数、最新更新时间戳 | **空间悬浮岛卡片**：<br>3D 景深悬浮卡片、弹簧阻尼回弹、光追亚克力高光（窄屏自动收敛为单列）       | **流体液态大标**：<br>高对比度渐变遮罩（scrim）遮蔽背景流光的大字标、液态引力统计条                  | 结构布局和交互模型完全不同，无法单靠 CSS 变量切换 |
| **2. 目录形态 (`Toc.vue` / 索引列表)** | **手册式点线列表**：<br>工整的点线引导符（Dot-leader）、章节代号（`01.COMP`）、单行高密度技术排版  | **网格悬浮卡片**：<br>亚克力微透视卡片、角标微徽章、悬停上浮与阴影漫反射                          | **液态高亮胶囊列表**：<br>有机流线胶囊、粘性（Gooey）光斑跟随滑动激活态                              | 视觉与 DOM 树交互形态差异大                       |
| **3. 背景层 (`Backdrop.vue`)**         | **工程标尺与网格**：<br>0 GPU 耗能的纯 CSS 12 栏参考线与坐标刻度                                   | **渐变光晕与引力光斑**：<br>CSS `backdrop-filter` 柔光球（严格限制同屏 ≤ 3 层，受 `--blur` 控制） | **原生 WebGL 着色器**：<br>Domain-Warping 原生 WebGL 流体着色器（仅首屏/目录运行，带离屏暂停与降级） | 底层渲染机制完全不同（无动画 vs CSS vs WebGL）    |
