# 常见的排序方法

以下五种排序算法均以初始数组 `5 1 4 2 8` 为例独立演示，各自推导排序过程与内存状态变化。

## 冒泡排序

遍历相邻两项并在逆序时交换，每轮将当前未排序区间的最大值推至最右端。若整轮未发生任何交换，说明数组已有序，可提前终止。

::::scrolly bubble

```java
public void bubble(int[] a) {
    for (int end = a.length - 1; end > 0; end--) {
        boolean swapped = false;
        for (int i = 0; i < end; i++) {
            if (a[i] > a[i + 1]) {
                int temp = a[i];
                a[i] = a[i + 1];
                a[i + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) return;
    }
}
```

## 选择排序

将数组划分为已排序区与未排序区。每轮扫描未排序区间找到最小值，将其与该区间首项交换。无论初始数据是否有序，比较次数均为固定的 $\frac{n(n-1)}{2}$ 次。

::::scrolly select

```java
public void selection(int[] a) {
    for (int start = 0; start < a.length; start++) {
        int min = start;
        for (int i = start + 1; i < a.length; i++) {
            if (a[i] < a[min]) min = i;
        }
        int temp = a[start];
        a[start] = a[min];
        a[min] = temp;
    }
}
```

## 插入排序

维护左侧已排序区间，逐个从未排序区间取出元素作为 `key`，在已排序区间中从后向前扫描，将大于 `key` 的元素依次后移，最后将 `key` 插入空位。

::::scrolly insert

```java
public void insertion(int[] a) {
    for (int i = 1; i < a.length; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}
```

## 快速排序

基于分治思想，选定基准值（Pivot）将当前区间划分为“小于等于基准”与“大于基准”两部分。将基准归位后，再对左右两子区间递归执行同样的分区操作。

::::scrolly quick

```java
public void quickSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}

private int partition(int[] a, int lo, int hi) {
    int pivot = a[hi];
    int i = lo;
    for (int j = lo; j < hi; j++) {
        if (a[j] <= pivot) {
            int temp = a[i];
            a[i] = a[j];
            a[j] = temp;
            i++;
        }
    }
    int temp = a[i];
    a[i] = a[hi];
    a[hi] = temp;
    return i;
}
```

## 堆排序

利用数组模拟完全二叉树（节点 $i$ 的左孩子为 $2i+1$，右孩子为 $2i+2$）。先自底向上建大顶堆，随后反复将堆顶最大值交换至末位，并对剩余区间缩小规模重新下沉调整。

::::scrolly heap

```java
public void heapSort(int[] a) {
    for (int i = a.length / 2 - 1; i >= 0; i--) heapify(a, a.length, i);
    for (int end = a.length - 1; end > 0; end--) {
        int temp = a[0];
        a[0] = a[end];
        a[end] = temp;
        heapify(a, end, 0);
    }
}

private void heapify(int[] a, int size, int root) {
    int largest = root;
    int left = root * 2 + 1;
    int right = root * 2 + 2;
    if (left < size && a[left] > a[largest]) largest = left;
    if (right < size && a[right] > a[largest]) largest = right;
    if (largest == root) return;
    int temp = a[root];
    a[root] = a[largest];
    a[largest] = temp;
    heapify(a, size, largest);
}
```

## 选型与工程权衡

| 算法         | 平均时间      | 最坏时间      | 最好时间      | 空间复杂度  | 稳定性 | 核心特征与场景                                                                                                                              |
| :----------- | :------------ | :------------ | :------------ | :---------- | :----- | :------------------------------------------------------------------------------------------------------------------------------------------ |
| **插入排序** | $O(n^2)$      | $O(n^2)$      | $O(n)$        | $O(1)$      | 稳定   | 数据量小（如 $n \le 16$）或几乎有序时开销极低。许多混合排序（如 Timsort、Dual-Pivot Quicksort）在子区间缩小时均以此收尾。                   |
| **冒泡排序** | $O(n^2)$      | $O(n^2)$      | $O(n)$        | $O(1)$      | 稳定   | 借助提前终止标志可在近有序数据下达到 $O(n)$ 比较，但每次逆序均发生相邻元素写入，写操作开销通常高于插入排序。主要用于教学。                  |
| **选择排序** | $O(n^2)$      | $O(n^2)$      | $O(n^2)$      | $O(1)$      | 不稳定 | 交换次数恒定为 $O(n)$。无论数据分布如何都必须完成全量比较，且跨步交换破坏稳定性，工程中极少单独使用。                                       |
| **快速排序** | $O(n \log n)$ | $O(n^2)$      | $O(n \log n)$ | $O(\log n)$ | 不稳定 | 缓存命中率高、常数因子极小，平均吞吐量在原地排序中最具优势；最坏情况依赖三数取中或随机基准规避。                                            |
| **堆排序**   | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$      | 不稳定 | 时间复杂度绝对稳定且严格 $O(1)$ 辅助空间。但树状跳跃访问对 CPU Cache 不友好，平均耗时通常慢于快速排序。适合对最坏停顿敏感且内存受限的系统。 |

**决策依据**：

1. **数据规模极小或近乎有序**：首选**插入排序**。当逆序对极少时，其内层循环能快速跳出，实际执行开销往往优于具有函数调用开销的高阶排序。
2. **多字段复合排序（需严格保序）**：在无额外内存分配的前提下，选用**插入排序**；数据量较大时选用具有稳定性的**归并排序（Merge Sort）**。
3. **追求通用吞吐量**：首选优化后的**快速排序**。通过三数取中避免极值分区，并在小区间切入插入排序以降低递归开销。
4. **硬性拒绝 $O(n^2)$ 最坏波动且禁止额外内存**：选用**堆排序**，以固定的 $O(n \log n)$ 上界保障系统下限。
