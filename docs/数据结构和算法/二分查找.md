# 二分查找

## 每次丢掉一半

二分查找只适用于**已经排好序**的数组。每次取中点比较：相等就返回，目标更大就丢掉左半，更小就丢掉右半。元素个数每比较一次大约减半，比较次数是 log₂ n。

```kotlin
fun binarySearch(nums: IntArray, target: Int): Int {
    var left = 0
    var right = nums.size - 1
    while (left <= right) {
        val mid = left + (right - left) / 2
        if (nums[mid] == target) return mid
        else if (nums[mid] < target) left = mid + 1
        else right = mid - 1
    }
    return -1
}
```

:::note 中点
`left + (right - left) / 2` 和 `(left + right) / 2` 的结果一样，但前者在 left、right 很大时不会把两者相加溢出。
:::

## 找 29

::::scrolly
:::step 01 · 准备
数组已经升序。要找的是 29。left 指向开头，right 指向末尾，查找范围是整段。
:::
:::step 02 · 第一次中点
mid = left + (right - left) / 2 = 5，对应的值是 21。21 小于 29，目标只可能在右半段，left 移到 mid + 1。
:::
:::step 03 · 丢掉右半
新的中点是 8，值是 33。33 大于 29，right 移到 mid - 1。左半那些比 21 还小的位置已经不在范围内。
:::
:::step 04 · 再收一次
现在范围内只剩 25 和 29。中点取到 25，仍然小于目标，left 再往右移一格。
:::
:::step 05 · 命中
left 和 right 重合在 29 上。中点的值等于目标，返回下标 7。十二个元素只比较了四次。
:::
::::

## 变的是比较条件

- **找不到时的插入位置**：循环条件改成 `left < right`，结束时 `left` 就是应该插入的下标。
- **旋转升序数组的最小值**：拿 `nums[mid]` 和 `nums[right]` 比。中点更大，说明最小值在右半，`left = mid + 1`；否则 `right = mid`。
- **整数平方根**：比较的不是数组元素，而是 `mid * mid` 和 x。比 x 小就把 left 右移，循环结束后 right 是不超过 x 的最大平方根。

:::note 边界
这些题仍然是每次丢掉一半。真正要分开的是：范围用 `left <= right` 还是 `left < right`，以及相等时返回 mid 还是继续收缩。
:::
