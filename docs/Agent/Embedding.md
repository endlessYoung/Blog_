# Embedding

## 1. Embedding 的定义

`Embedding` 就是把现实中的东西——一个词、一句话、一张图、一段代码去映射成一串固定长度的向量。
这个向量不是随机的，它必须做到：

- 相似的东西，向量在空间里挨得近。
- 不相似的东西，向量在空间里离得远。

做一个简单的比喻就是：`餐厅的菜单坐标`
如果你把全城的美食店都标在一个二维地图上，那么火锅店都在左上方，咖啡馆都在右下角。
那么（x,y）坐标就是这家店的 `Embedding`。
只要看一眼坐标，就知道两家店的口味是否相像。

再或者将其比喻成：`乐高的数字身份证`
每一个乐高积木都有一个唯一ID，但是这个ID不表示任何关系。`Embedding` 就像是一串描述性的数字，比如：“尺寸”、“凸点数量”、“颜色RGB”。功能相似的积木数字的也接近。
则在数学上，这个就是一个函数：

Embedding(输入) $\rightarrow \mathbb{R}^d$

d 是维度，比如 768、1536。一旦有了这个向量，你就能用加减乘除计算语义。

## 2. 为什么非要用 Embedding 不可？

### 2.1 计算机只懂得数字，不懂得“意思”

如果你只给计算机一个词“猫”，那么它完全不知道是什么，以前最原始的办法叫做 One-Hot 独热解码：
词表有10万个词，“猫”就表示为[0,0,0,0,1,0,0...]，只有一位是1，其余都是0。

这样就有一个致命缺陷：

- 如果维度升高至10w维度，会造成维度灾难。里面几乎都是0。
- 看不出任何关系：“猫”可能和“核聚变”是相近的意思。

## 2.2 人类语言的本质就是稠密、连续的关系

语义是渐变的：国王 -> 王后，男人 -> 女人，走路 -> 跑步。高纬稀疏的独热码无法表达这种连续过渡。
`Embedding` 把实际世界映射到一个低维、稠密的连续空间中。用距离代表相似度，方向代表属性差异。

## 2.3 现代智能体必须做到软匹配

当用户问AI Agent，“如何退款”，其知识库里存的是“退货政策”。他们字面上完全不同，必须考 `Embedding` 来发现它们语义高度重合，才能正确召回只是。如果没有，所有智能体都只是关键词匹配机器。
