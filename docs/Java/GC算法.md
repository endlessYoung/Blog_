# GC算法

## 怎么判断对象已死

回收之前先要知道哪些对象不可能再被用到。堆和方法区是主要发生垃圾回收的地方。

### 引用计数

每个对象带一个计数器。多一处引用就加 1，引用失效就减 1，计数到 0 就可以回收。两个对象互相引用、外面已经没人指向它们时，计数都还是 1，回收不掉。这就是循环引用。

### 可达性

HotSpot 用的是可达性分析。从 **GC Roots** 出发，顺着引用往下走。走不到的对象就是不可用的，哪怕它们彼此还连着。

能当根的包括：栈帧里的局部变量、类的静态字段、常量（包括字符串常量池里的引用）、JNI 引用、被 `synchronized` 锁住的对象，以及虚拟机自己的一些常驻对象。

## 三种回收

对象确认存活之后，回收有三种做法：标记清除、复制、标记整理。它们面对的是同一段内存，不是前后接上的四步。这段内存里活着的是 A、B、C，夹在中间的三格已经没有引用。

::::scrolly
:::step 01 · 标记清除法
先从 GC Roots 把 A、B、C 标成存活，再把没被标记的格子清掉。活对象留在原地。空出来的是一块一块的洞，下一次分配只能沿着空闲链表找能放下的洞。
:::
:::step 02 · 复制法
不是接着清除的结果做，还是从原来那一段出发。内存分成 From 和 To，只把活对象按顺序抄到 To 的开头，From 整块丢掉。To 里剩下的空闲连在一起，分配时移动堆顶指针就行。代价是有一半空间在备用。
:::
:::step 03 · 标记整理法
也从原来那一段出发。先标记，再把活对象往这一段内存的一端滑动，紧挨着排好，后面整段变成连续空闲。不预留半区。对象被移动之后，指向它们的引用都要改，这一步必须停掉用户线程。
:::
::::

## 分代

大多数对象活不长；熬过的轮次越多，越不容易死；跨代引用相对少。所以年轻代用复制，老年代用标记-清除或标记-整理。

年轻代的 Eden 和两个 Survivor 按 8:1:1 来划，细节在 [伊甸园区算法](/Java/伊甸园区算法)。一次 Minor GC 后存活对象装不下 Survivor，就由老年代做分配担保，直接晋升。

### 卡表

年轻代里的对象可能被老年代引用。如果为此去扫整个老年代，Minor GC 就变成全堆扫描。HotSpot 用卡表：老年代按 512 字节切成卡页，卡表里每个字节对应一页。这一页里有字段指向年轻代，该字节就标成 dirty。Minor GC 只扫 dirty 的页。

赋值器写下 `obj.field = value` 时，写屏障把字段所在的卡标脏。

```c
void post_write_barrier(oop* field, oop new_val) {
    // 地址右移 9 位，对应 512 字节的一张卡
    CARD_TABLE[((size_t)field) >> 9] = 0; // 0 表示 dirty
}
```

## 三色标记

标记如果全程停住用户线程，大堆会停很久。并发标记让收集线程和用户线程一起执行。对象按扫描进度分成三色：

- **白色**：还没访问过。这一轮结束时仍是白色，就是垃圾。
- **灰色**：自己访问过了，直接引用的对象还没扫完。
- **黑色**：自己和直接引用的对象都扫过了，不会再扫它的直接引用。

### 漏标

用户线程中途改引用，可能多留一点浮动垃圾，下一轮再收，这不影响正确性。漏标才会把活对象当成白色收掉。

漏标要同时发生两件事：黑色对象新插入一条指向白色对象的引用；灰色对象删掉了所有通向这个白色对象的引用。黑色不会再被扫描，灰色又走不到它，白色就丢了。

### 增量更新与 SATB

打破任意一个条件就够了。

- **增量更新**，CMS 用。写后屏障记下黑色对象新插入的引用，并发标记结束后把这些黑色对象退回灰色再扫一遍。重新标记阶段仍然要停一会儿。
- **原始快照 SATB**，G1 用。写前屏障记下被删掉的旧引用。不管后来引用怎么改，都按这一轮开始时的对象图判断存活。

## 怎么选

- **标记-清除**：空间都能用，不移动对象，但会留下碎片，之后只能走空闲链表。CMS 的清除阶段是这一路。
- **复制**：没有碎片，分配只移动堆顶指针。耗时跟存活对象的数量走，年轻代合适。传统半区只用一半内存，Appel 式能用到大约 90%。
- **标记-整理**：也没有碎片，也不预留半区。移动对象还要改全部引用，停顿更重。老年代常用。

## 停顿被挪到并发

堆从几 GB 涨到上百 GB 之后，停顿本身成了问题。后面的收集器是在把原来停住的阶段挪到和用户线程一起执行。

- **CMS**：标记和清除可以并发。整理仍然要停，浮动垃圾多了会 Concurrent Mode Failure，退回 Serial Old。
- **G1**：堆切成同样大小的 Region，按停顿预测挑回收哪些区。并发标记用 SATB。
- **ZGC**：染色指针用 64 位地址的高位记下标记状态，读屏障在线程读到旧地址时把指针改过来。标记、转移、重定位都可以并发，停顿和堆的大小解开。
